# Library Management System

A simple menu-driven Library Management System built in Python using file handling. It manages books, students and book issue/return records.

## Features
- Issue and return books
- View books not yet returned
- Add new books and students
- Book history and student history
- Search book and search student

## Files
- `library.py` - main program
- `all_books.txt` - book records
- `all_students.txt` - student records
- `all_issued.txt` - issue/return records

## How to Run
1. Install Python 3
2. Keep all files in the same folder
3. Run: `python library.py`

## Concepts Used
Python, File Handling, Functions, Loops, Date handling
